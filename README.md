# PALMA Dashboard

Dashboard web de Distribuciones Palumar S.A.

## Estructura

- index.html: estructura HTML
- css/styles.css: estilos visuales
- js/config.js: configuración general
- js/utils.js: utilidades
- js/api.js: conexión con Google Apps Script
- js/charts.js: gráficas Chart.js
- js/render.js: renderizado de vistas y tablas
- js/app.js: inicialización del dashboard
